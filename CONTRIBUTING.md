# Contributing Guide

Thank you for contributing to the Repository Custodian Demo.

## Making Changes

Before submitting a change:

1. Read the project documentation.
2. Make a small and focused change.
3. Run the available tests.
4. Update documentation when behaviour changes.
5. Provide a clear description of the change.

## Code Changes

Changes to application behaviour should include appropriate tests.

For example, if a new temperature conversion feature is added, the corresponding test should also be updated.

## Documentation Changes

Documentation should describe the current behaviour of the application.

If installation steps, supported features, or usage examples change, the README should be updated.

## Issues

When reporting an issue, include:

* A short description of the problem.
* Steps to reproduce the problem.
* Expected behaviour.
* Actual behaviour.
* Any relevant error messages.

Clear issues help the Repository Custodian understand and triage repository problems.
